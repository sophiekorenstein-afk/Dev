### Step 1: Choose Your Path

**I'm new to this library**
→ Start with README.md

**I want to get started quickly**
→ Use QUICK_REFERENCE.md

**I need to install it**
→ Follow INSTALLATION.md

**I need detailed API docs**
→ Study API_REFERENCE.md

**I want to see examples**
→ Check EXAMPLE_USAGE.lua

### Step 2: Load the Library

```lua
local UILibrary = loadstring(game:HttpGet("https://raw.githubusercontent.com/yourusername/lua-ui-library/main/UILibrary.lua"))()
```

### Step 3: Create Your UI

```lua
local UI = UILibrary.new("My Script", "v1.0")
local Tab = UI:CreateTab("Main", "🏠")
UI:AddButton(Tab.Name, "Click Me!", function()
    print("Clicked!")
end)
```

### Step 4: Enjoy!
